# 视觉与兼容约定

正式编辑器、材料样本、图例与导出共用核心规则和绘图包。固定样例见[制图场景](./fixtures/cartography-gallery.json)与[星湾地图](./fixtures/visual-estuary.json)，PNG 对照位于 [gallery](./gallery/)。

## 工作区

桌面由文档栏、工具栏、画布和默认展开的上下文侧栏组成；可固定另一侧栏并调整宽度。窄屏使用可收起、半屏或展开的单个面板，字段区独立滚动，操作区保持可达。

| 操作 | 反馈与提交 |
| --- | --- |
| 材料绘制 | 显示刷入字段与覆盖范围，松开提交一次手势，取消恢复 |
| 单格或批量修改 | 显示草稿、混合值与真实变化数量，应用或还原 |
| 河流编辑 | 显示节点、宽度及连接预览，一次拖动对应一次撤销，提供键盘操作 |
| 导出 | 显示实际范围、像素与预览，通过任务状态生成、取消或下载 |

表单草稿独立于显示缓存。文档菜单管理地图和连接设置；撤销、重做、保存状态、历史与任务有明确入口。

界面使用中性面板与有限绿色强调，正文以 14px 为基础、触摸输入 16px、辅助文字至少 12px。间距采用 4/8/12/16/24/32px，主要触摸入口至少 44px。活动、焦点和错误同时使用文字或形状反馈，深浅主题覆盖浮层和表单，动画尊重减少动态效果设置。

## 地图表达与输出

地貌底色与符号、生态纹理、河流、标记、文字和编辑反馈依次叠加。标签采用适配底色的颜色或衬底。近景显示细节，中景保留主要地形与河网，远景使用聚合地形和独立简化河网；阈值有缓冲，纹理以世界坐标定位。

工作区主题与 `meta.map_style` 独立。新地图使用 `atlas-v1`，缺少样式字段的旧地图使用 `classic-v1`；样式变更参与修订、预演和撤销。原有地形及生态键保持兼容。

开放水域合成后只绘外岸线。同样式的显式连接河流按水系合成；不同样式重叠由宽河优先，同宽按 ID 排序。轴向约束曲线、连续河带和圆形连接处理急弯；范围裁切保留连续片段，裁切端部不继承远处源头或河口语义。湿地与三角洲不代表整格开放水面。

预览和 PNG 共享场景及排版，预览最长边 1000px，显示原图像素尺寸。导出读事务固定地图修订，`expectedRevision` 可拒绝过期预览。标题、图例、说明及格距有独立区域；图面方向和格距不冒充地理方向或真实距离。

## 河网契约

- `junction_id` 相同表示显式连接，所有参与点共用坐标；视觉交叉不自动建立连接。
- `flow_direction` 为 `unspecified`、`forward` 或 `reverse`，修改流向保持宽度锚点位置。
- `start_kind` / `end_kind` 为 `auto`、`spring`、`water` 或 `open`；自动判断参考实际水面与明确连接。
- 旧数据缺少网络字段时保持未指定或自动；导入验证共享节点坐标一致性。

`connect_river_points` 将参与点连接到第一个点；合并已有连接时同步全部成员。`disconnect_river_point` 解除一个点。修改共有点时同步其他成员，非法路径使整次操作失败；逆操作以 `restore_rivers` 原子恢复相关河流。Y 形汇合与分汊共用节点结构，通过流向区分。

## 河宽兼容

新河流使用 `width_mode: distance`，按锚点间累计六角格路径长度插值；细分同一路径保持宽度分布。无锚点时宽度为 4，锚点之外延续最近宽度。

缺少 `width_mode` 的旧数据读取为 `legacy`，保持控制点序号插值；查看和导出保留该模式。编辑旧河流前，先将原有效宽度固定为显式锚点，再切换距离规则；界面草稿同步显示这些锚点，显式 `null` 移除锚点。

普通命令采用新宽度规则时，在历史摘要中记录 `rules_version: 2`；旧条目按原规则回放。合并使用单独的变更历史。逆操作和内存快照保留原模式与锚点。JSON 归档保存地图内容，持久撤销历史随 SQLite 备份保存。

回归覆盖宽度细分、不等长河段、旧 JSON 往返、旧河流重命名与新旧操作交错撤销；实现位于核心包 `rivers.ts`、`serialization.ts`、`commands.ts` 和服务端历史执行器。
