# 编辑器与地图视觉规范

日期：2026-10-03。用于执行视觉重构计划的第 2—7 阶段。原型以正式编辑器和本目录固定地图为基础逐步实现，每个状态验证后保留为产品实现。

## 工作区

桌面使用文档栏、窄工具栏、画布和一个默认展开的上下文侧栏。材料绘制时展开材料库，选择对象后显示属性；用户可固定另一侧栏。面板宽度可调并记忆。文档菜单容纳新建、切换、导入、重命名与连接设置；撤销、重做、保存状态和导出常驻。

属性顶部以一行说明当前对象，下面直接呈现核心字段。工具参数只在该工具活动时显示。历史与任务有独立入口。窄屏使用可收起、半屏、展开的单个面板；字段独立滚动，主操作保持可达。

| 当前任务 | 主要入口 | 主要反馈 | 完成/取消 |
| --- | --- | --- | --- |
| 画地形 | 地形与生态样本卡、材料笔刷 | 当前材料、刷入字段、笔刷覆盖范围 | 松开提交一次手势，取消恢复 |
| 改单格 | 选中格子的上下文属性 | 实际样本、字段修改状态 | 应用或还原 |
| 批量修改 | 多选工具与批量属性 | 数量、混合值、保持/设置/清除 | 预演影响范围后应用 |
| 画河流 | 河流工具和路径节点 | 预览、当前点、起终点与宽度 | 完成或取消绘制 |
| 改河流 | 画布命中或全图对象列表 | 节点、宽度手柄、连接提示 | 一次拖动一步撤销，属性明确应用 |
| 导出 | 文档栏导出 | 实际范围、图例、背景和尺寸预览 | 生成、取消、下载 |

## 界面视觉

- 中文系统字体，正文和字段以 14px 为基础，触摸输入 16px；辅助文字至少 12px。
- 中性浅色面板、深色墨绿文字、有限的绿色强调色；地图使用独立的自然配色。主要按钮、选中与焦点同时有形状或文字反馈。
- 间距使用 4/8/12/16/24/32px；常用控件 36px 起，触摸主要入口至少 44px。
- 图标采用统一 SVG 线条，提供名称和快捷键提示。浮层、表单、任务提示一起覆盖深浅主题。
- 动画只表达状态转换，尊重减少动态效果设置。滚动区、浮层和固定按钮各有明确尺寸边界。

## 地图表达

地形颜色表达地貌家族，地貌符号表达山地、丘陵、峡谷等形态，生态以稀疏的树木/草地/湿地纹理叠加。主要标记使用统一图形。图例、材料卡、画布和输出使用相同的绘图函数。

近景提供格子和详细符号，中景保留主要地形、标记和河网，远景抑制纹理及坐标。标签有适应底色的颜色或衬底，活动对象信息始终可发现。地图样式按 classic-v1 与 atlas-v1 保存；旧图默认经典，新图默认自然样式。工作区深浅主题不改动地图样式。

## 水系数据约定

- 河宽以当前地图绘图单位保存，沿路径距离插值；旧规则按兼容说明保留。
- 流向为未指定、顺路径或逆路径，修改流向不反转宽度锚点的位置。
- 控制点可携带 junction_id。只有明确共享同一节点标识才表示连接；视觉交叉不自动连接。
- 一个连接节点的所有参与点共用坐标。移动节点会同步更新参与河流，并作为一个可撤销命令提交；解除连接只移除所选点的关联。
- 起终点类型可为自动、源头、接水或开放端；自动判断只参考实际水面和明确连接。地形为海岸、湿地、三角洲不代表整格开放水面。
- 支流、分汊和独立交叉均可表达。导入时检查节点坐标一致性，旧图缺少连接/流向字段时保持未指定。

约定已经落入核心命令和数据库。`connect_river_points` 将所选控制点连接到第一个点；合并已有连接时同步其全部成员。`disconnect_river_point` 解除一个点。`update_river`/`set_river_path` 移动共有点时同步其他成员；任一河流出现相邻重叠等非法路径时整次操作拒绝。撤销以 `restore_rivers` 原子恢复本次影响的全部河流，避免逐条恢复时产生临时断裂。

`flow_direction` 为 `unspecified/forward/reverse`；`start_kind`、`end_kind` 为 `auto/spring/water/open`。反转方向只改流向字段。Y 形汇合与分汊使用相同的共享节点结构，通过流向区分；穿湖路径保留各自控制点，以端点类型或实际水面决定合成；独立交叉不设共享标识。旧文件和旧数据库缺少上述字段时读取为未指定/自动。

样式存放在 `meta.map_style`。缺失时为 `classic-v1`，新地图为 `atlas-v1`；`set_map_style` 参与修订检查、预演和撤销重做。SQLite 增加可空字段，原 JSON 不重写，兼容测试覆盖往返导出。变更前已备份真实数据库和地图文件到本机临时目录。

## 最终地图表达与输出

atlas-v1 使用地貌底色、稀疏地貌符号、独立生态纹理和地点徽记。底色与地貌线形、生态、河流、标记、文字、编辑反馈按顺序叠加；标签有适配底色的文字及衬底。多标记限制可见数量，完整数据保留在属性和悬停说明。

水面从明确的开放水域格生成，只有外边界绘岸线。显式连接的同样式河流按一个水系合成；不同样式的局部重叠由宽河优先、同宽按 ID 排序。曲线采用受约束的轴向 Hermite 插值，河带以连续四边形和圆形连接合成，防止急弯破洞及偏移岸线退化。裁切保存连续片段，虚拟边界端部不携带源头或河口语义。

远景概览的河流使用独立简化路径，保持进出视口的分段；地形概览不再因河流经过而整体染蓝。显示细节有不同的进入/退出阈值，减少缩放临界点闪变。纹理随格子尺寸缩放并以世界坐标为基准定位，材料样本使用独立尺寸的定义，避免图例与地图互相覆盖纹理定义。

导出预览与 PNG 共享范围准备、场景构建、SVG 和成图排版。预览最长边 1000px，显示原图像素尺寸；后台任务在独立数据库读事务中保持同一修订，实际导出可用 expectedRevision 拒绝过期预览。标题、说明、图例和格距有独立区域，透明图片上的说明区域保留浅底。图面方向不等同于地理坐标，格距不冒充真实距离。

兼容：保留已有地形与生态键；旧地图缺少样式字段时使用 classic-v1，旧河流缺少网络字段时保持未指定；旧宽度转换见 [专门说明](../../RIVER_WIDTH_COMPATIBILITY.md)。原存储备份和数据库历史恢复已验证，JSON 归档不携带撤销历史。
