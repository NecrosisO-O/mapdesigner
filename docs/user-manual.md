# MapDesigner 用户手册

MapDesigner 是本地优先的六角格地图编辑器。地图和撤销历史保存在 SQLite，JSON 用于交换与归档。

## 地图与工作区

顶栏“地图”菜单提供切换、新建、导入、重命名、另存为、复制、删除和连接设置。新地图从七格种子区域开始，设计一个格子后提供邻接待设计格。删除同时移除历史，无法撤销。需要令牌的部署在连接设置中输入令牌。

文档栏显示地图名称、保存状态、撤销重做、主题、专注画布和导出。工具栏提供选择、平移、材料笔刷、取样、河流和批量。材料与对象侧栏包含材料、对象、图例和显示；属性面板跟随选中的格子或河流；历史从顶栏独立打开。

默认展开一个侧栏，可调整宽度、固定第二面板或进入专注模式。窄屏面板支持收起、半屏和展开，内容独立滚动。工具和面板切换保留草稿，切换地图等操作会提示处理未应用修改。提交失败时保留草稿和重试入口。

## 材料、单格与笔刷

材料库提供 36 种地形、30 种生态的实际样本、分类、搜索、简释和最近使用记录。选材料后直接用笔刷绘制，可选单格、7 格或 19 格，也可只刷地形或生态；取样工具从已有格子读取材料。

单格属性首屏显示地形与生态，标记和备注按需展开。不兼容的地形转换会解释生态清除结果。“应用修改”保存草稿，“还原”恢复原内容。平移离开格子不会丢失草稿。

格式刷复制选中格子的指定字段，包括标记与备注。笔刷或格式刷的一次拖动只提交一次，可一步撤销；Escape 或指针取消会放弃当前手势。

## 批量修改

批量工具通过点击加入或移出格子，选区不随视口变化。面板显示混合值、选择数量和真正改变的数量。字段默认保持原值，仅明确设置或清除的字段会改变；标签可替换、追加或移除。没有变化时不提交空操作。

全图替换地形或生态先展示服务器预演结果，再确认应用。修订冲突时需重新读取地图，核对其他操作的结果。

## 地图样式与图例

- 底色表示地貌家族，山峰、圆丘、沙脊、冰裂等形状补充地形信息。颜色不表示实测海拔或水深。
- 生态以树木、草地、湿地等纹理表达。细分类结合实际材料样本、悬停信息和图例理解。
- 地点使用图形标记。同格最多直接显示两个，余量用数量提示，属性仍保留所有标记。
- 图例默认显示整张地图使用的类型，可切换完整图例；点击暂时高亮对应格子，再次点击取消，不修改地图。
- 显示入口控制地貌、生态、河流、标记、坐标、简写、网格和待设计格。标签筛选独立于图层显示。

新地图使用 atlas-v1 自然样式；缺少样式字段的旧地图使用 classic-v1。显示设置中可切换，支持撤销。工作区深浅主题独立于地图样式，切换主题不改变导出地图颜色。

## 河流直接编辑

河流工具中依次点击路径点，至少两个点后完成。可在画布选中河流，或在对象侧栏按名称搜索全图河流并定位。列表采用分页，超过 200 条仍可查找。

选中后显示节点及河宽。拖动圆点改路径，双侧方块改宽度；松开提交一次，Escape 取消。属性中可精确输入坐标、插入或移除节点；节点和宽度手柄有键盘操作。表单草稿需先应用或还原，再直接拖动。

宽度以地图绘图单位保存，沿路径累计距离插值，不表示真实流量。缩放不改变保存值，清空节点宽度可恢复自动插值。等宽、渐宽和局部收窄是可继续修改的起始方案。旧河流进入编辑时保留有效宽度，见[宽度兼容说明](./RIVER_WIDTH_COMPATIBILITY.md)。

## 连接、分汊与水面

流向可为未指定、沿路径或逆路径，改变流向保留原位置的宽度。只有明确连接的节点才表示汇流或分汊，视觉交叉不会自动连接。

绘制时可启用节点吸附，也可从属性建立或解除连接。移动共有节点同步更新相连河道，整次操作可一步撤销。从已有节点创建分支，分支路径独立编辑，起点连接与创建一起提交。

海洋、近海和湖泊等开放水面连续绘制，只有外岸线。河道进入水面后隐藏内部色带，编辑时仍保留路径。海岸、沙滩、湿地和三角洲属于地貌，不等于整格开放水面；三角洲由用户选择地形并绘制分汊组合表达。

同样式的显式连接水系合成一次，避免接头叠色；不同样式重叠区由宽河优先，同宽按固定对象标识排序。源头可收束，接水端结合真实水面边界过渡。合理性建议可定位并忽略，不是高程、流量或物理水文模拟。

## 大地图与历史

远景使用有上限的地形概览，河网作为独立线条保留；不会把河流经过的整个概览块染成水域。放大后逐步显示地貌、生态、标记和坐标，阈值有缓冲。缓存有格数和路径点预算。

历史面板显示修改对象、已应用或已撤销状态；撤销后的记录保留为可重做项。旧历史缺少新摘要时仍可恢复。性能与兼容记录见[视觉验收](./research/2026-10-03/visual-redesign/README.md)。

## 导入、导出与备份

JSON 导入在后台执行，可查看阶段并取消。上限为 64 MiB、50 万格、2 万条河流和合计 50 万个路径点。ID 冲突时可生成新 ID 重试；失败或取消不发布半张地图，已开始最终提交时需等待结果。

导出窗口默认全图、纯净样式和本图图例。可设置当前区域、倍率、边距、标题、说明、图例、方向标、格距、图层和透明背景，也可明确复制当前画布的显示选项。

真实预览显示像素尺寸、格数和修订号，可放大检查细节。生成前检查修订，地图改变时需更新预览。透明背景下标题和图例仍保留浅底；方向标表示图面朝上，未定义真实距离时只显示相邻格心的格距，不显示公里。

PNG 上限：全图 10,000 格，区域 25,000 格，单边 32,768 像素，总计 4,000 万像素。超限时缩小范围或倍率，完整归档使用 JSON。任务有进度、取消、失败重试和再次下载入口，下载凭证五分钟有效，失效后重新导出。

JSON 不包含撤销历史。连同历史备份使用 pnpm backup，见[部署说明](./deployment.md)。旧地形和生态键不变，样式及网络迁移见[视觉规范](./design/editor-v3/README.md)。

## 快捷键

| 按键 | 操作 |
| --- | --- |
| V / H / B / I / R / M | 选择 / 平移 / 材料笔刷 / 取样 / 河流 / 批量 |
| 空格 + 拖动 | 画布临时平移 |
| 方向键 / Enter | 移动格子焦点 / 对当前格操作 |
| Shift + Enter | 绘河时添加当前焦点格 |
| ⌘ / Ctrl + Enter | 应用单格草稿 |
| ⌘ / Ctrl + Z；加 Shift | 撤销；重做 |
| F / + / − | 适合画布 / 放大 / 缩小 |
| Escape / ? | 取消手势或关闭浮层 / 帮助 |

表单输入不会触发工具快捷键。鼠标滚轮以指针为中心缩放，触摸指针实现双指缩放。桌面、受控尺寸与键盘检查已记录；真实手机触摸、软键盘、安全区域、读屏、浏览器 200% 页面缩放及首次使用者测试仍待人工完成，不能用模拟代替。
