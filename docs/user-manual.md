# MapDesigner 用户手册

MapDesigner 是本地优先的六角格地图编辑器。地图支持地形、生态、标签、备注和独立河流图层。
地图与历史保存在本地 SQLite；JSON 用于交换与归档。

## 打开和管理地图

运行方式见 deployment.md 或 docker.md。顶栏“地图”菜单提供选择、新建、导入、重命名、另存为、复制和删除。
新建地图从七格种子区域开始；设计一个格子后自动提供相邻待设计格，用于继续扩图。
名称修改先成为草稿，点击保存后写入服务器。单格、批量和河流修改通过各自的“应用”按钮保存。
删除会移除该地图及其操作历史，确认前核对名称；删除无法撤销。

如果服务要求令牌，在“地图 → 连接设置”输入部署时配置的值。
切换、新建、复制、导入或关闭页面时，未应用修改会触发保护提示；提交中需要等待操作完成。

## 工作区

- 顶栏：地图名称、保存状态、撤销重做、主题、专注模式与导出。
- 左侧工具：选择、平移、笔刷、河流、多选。
- 内容栏：显示坐标、简写、网格、待设计格、标签筛选和当前区域的河流列表。
- 中央画布：地图与缩放按钮；状态栏显示操作结果和修订号。
- 属性栏：单格、批量、河流、历史四个标签页。

内容栏和属性栏可以关闭；窄屏使用抽屉。专注模式把空间留给画布。
深色主题调整编辑器界面，地图本身保留制图配色。

## 单格与笔刷

选择一个格子，设置地形分类、地形、生态、标签和备注，再点击“应用”。
地形与生态选项受共享规则约束；不兼容组合会提示修改。“还原”丢弃该格草稿，“清空”移除已设计内容。
草稿与选区独立于视口，平移离开该格不会丢失编辑。

笔刷使用已设计的选中格作为来源，可以分别选择刷地形、生态、标签、备注。
拖动经过多个格子，松开后整次手势作为一次修改提交，可以一步撤销。Escape 或指针取消会放弃当前手势。

## 批量修改与全图替换

多选工具通过点击加入或移出格子。每个字段默认“保持原值”；只有选择“设置”或“清空”的字段会变更。
地形不能清空为无效状态；需要删除已设计内容时使用单格清空。
标签可替换、追加或移除指定标签。不同格子的未指定字段各自保留。

属性栏的批量页也提供全图地形/生态替换。执行前会显示服务器预演的影响格数，确认后才提交。
修改失败时保留草稿，修正后可以再次应用；遇到修订冲突时先重新打开地图确认其他操作的结果。

## 河流

选择河流工具，在地图上依次点击路径点，至少两个点后点击“完成”。
河流页可修改名称、颜色、透明度、路径坐标和宽度锚点。例：路径 R0C0, R1C0, R2C1；宽度锚点 R0C0:2, R2C1:8。
宽度锚点必须在路径上。删除河流属于可撤销的地图操作。
当前区域的河流也可以从内容栏选择。地图只有河流时，适合画布会使用河流范围。

## 大地图

缩小时显示覆盖完整范围的概览，放大后加载精确单元格。概览中颜色表示主要地形和河流覆盖，不能直接逐格编辑。
按区域加载只影响显示，选区和草稿仍保留。缓存有固定预算，长时间平移不会无限累积已访问范围。

## 导入与导出

“地图 → 导入 JSON”直接上传文件。后台任务显示当前阶段，可以取消。
ID 冲突时可生成新 ID 后重试。导入最多 64 MiB / 50 万格 / 2 万条河流，河流路径总计最多 50 万格。
失败或取消不会留下半张地图；任务进入最终提交后需等待结果。

顶栏“导出”提供 PNG 和 JSON。PNG 可选择当前加载范围或全图、简洁/参考预设、倍率、边距、图层和透明背景。
PNG 有格数和像素预算；大地图优先按范围导出，完整归档使用 JSON。
JSON 不含撤销重做历史；需要连同历史备份时使用 pnpm backup，参见 deployment.md。

## 快捷键

| 按键 | 操作 |
| --- | --- |
| V / H / B / R / M | 选择 / 平移 / 笔刷 / 河流 / 多选 |
| 空格 + 拖动 | 焦点在画布时临时平移 |
| 方向键 / Enter | 移动格子焦点 / 对当前格操作 |
| Shift + Enter | 河流工具中添加当前焦点格 |
| ⌘ / Ctrl + Enter | 应用单格修改 |
| ⌘ / Ctrl + Z | 撤销；同时按 Shift 重做 |
| ⌘ / Ctrl + S | 保存地图名称草稿 |
| F / + / − | 适合画布 / 放大 / 缩小 |
| Escape | 取消手势或关闭对话框 |
| ? | 快捷键说明 |

表单输入时不会触发工具快捷键。鼠标滚轮以指针位置缩放，触摸指针支持双指缩放。
真实触摸设备、软键盘和读屏仍需人工验收；当前自动化验证主要覆盖 DOM、指针事件和服务行为。
