制定日期：2026-10-03。评估基线：8b12901。执行顺序更新：2026-10-03。状态：自主实施中；各项以勾选和验证记录为准。

依据：[视觉、布局与制图表达评估](./research/2026-10-03/visual-audit/README.md)。下文“证据”编号对应该报告。此前六阶段功能重构已完成，本清单用于下一轮视觉与编辑体验改造。

## 目标与设计方向

用户已允许重构整体布局、面板内部、导航、地形图例和水系表现。目标是让地图容易阅读、材料容易选择、对象容易编辑，常用动作无需在多个面板间来回寻找。

采用清晰、克制的自然地图风格：界面使用中性色和有限强调色；地形使用有组织的颜色家族、地貌符号和稀疏生态纹理；水系使用连续水面、清楚的岸线和可控的宽度过渡。地形细分类通过图例及近景信息补充，避免所有信息在远景同时出现。

| 区域 | 新的职责 | 默认呈现 |
| --- | --- | --- |
| 文档栏 | 地图管理、名称、保存/提交状态、撤销重做、导出 | 单行，状态始终可发现，低频设置进入菜单 |
| 工具栏 | 选择、平移、材料笔刷、取样、河流、多选 | 一个活动工具，统一图标与可发现的名称/快捷键 |
| 工具选项 | 笔刷范围、当前材料、河流绘制状态等 | 随当前工具变化，临近画布 |
| 材料与对象侧栏 | 地形库、生态库、图例、对象查找和显示控制 | 绘制时优先展开材料；各部分有明确入口及搜索 |
| 属性面板 | 选中单格、多选对象或河流的属性 | 随选中对象变化；主要字段在首屏，其他内容按需展开 |
| 地图画布 | 编辑、选择反馈、预览和缩放 | 默认桌面状态使用单个展开侧栏；用户可固定第二侧栏 |
| 窄屏面板 | 当前工具或对象的核心操作 | 单个可调整高度的抽屉，滚动内容与操作区互不覆盖 |

显示设置、选择状态、草稿和地图数据各有明确归属。组件重构沿用已建立的命令、修订检查及历史机制，新增绘图和交互能力通过这些机制提交。

## 优先级与使用方式

- **P0：先修复。** 已复现的地图表达错误或主要操作遮挡；先做小范围修复和行为回归。
- **P1：主体重构。** 达到新的布局、可读性和水系表现要求所必需的工作。
- **P2：完成体验。** 历史/帮助、成图排版和合理性提示等收尾项，仍属于这份完整清单。

每项包含调整内容、依赖和验收条件。实施后附对应提交与验证记录，再勾选；不能只凭页面无报错或自动测试通过勾选视觉验收。

## A. 设计基础与数据约定（4 项）

- [ ] **F01 · P1 · 固定设计方向与任务原型。**
  制作包含地形绘制、单格修改、多选、河流编辑和导出预览的工作区原型；以山地、森林、海岸、河网混合样例验证信息层级。证据：U01、U04、C01。依赖：无。验收：1440×900 与 375×812 原型均能明确看出当前工具、对象、主动作及结果；关键任务具有完整起止状态。

- [ ] **F02 · P1 · 建立共享视觉规范和组件职责。**
  定义字号、间距、色彩、边框、图标、焦点、浮层及地图绘图的语义变量；明确工具、属性、图层、选择、草稿的驱动关系，清理重复样式和状态入口。证据：U02、U04、U08、C05。依赖：F01。验收：常用控件和地图样式有统一来源；活动工具与属性上下文不存在相互矛盾的显示。

- [ ] **F03 · P1 · 明确水系的最小数据约定。**
  设计可选流向、显式连接节点、端点类型及分支关系；约定宽度的地图单位、曲线和端点语义。旧河流的流向和连接默认为未指定，视觉相交不自动成为汇流。证据：R03、R04、R06。依赖：无。验收：汇合、分汊、穿湖、独立交叉及未指定方向均有可表达的数据示例；文档说明哪些信息可从地形推断、哪些必须由用户确定。

- [ ] **F04 · P1 · 设计兼容迁移与恢复。**
  保留地形及生态既有键，展示分类通过映射调整；水系新增字段纳入版本化读写、命令和历史。河宽规则变化前，对旧图中控制点的有效宽度作兼容转换，保存原文档以便恢复；新增控制点按新规则处理。证据：R01、R06、C04。依赖：宽度兼容与 R01 同批完成；其余水系字段兼容依赖 F03。验收：旧 JSON、数据库、历史记录都能恢复和往返导出；未知流向保持未指定；已有有效宽度不会在无说明的情况下改变；连接编辑撤销后恢复原状态。

## B. 工作区、导航与编辑流程（10 项）

- [ ] **L01 · P1 · 重构工作区空间分配。**
  实现文档栏、工具栏、上下文工具选项和可收起/调宽的侧栏；绘制与检查任务各有默认布局，记住用户固定面板的偏好。证据：U01、U04。依赖：F01、F02。验收：1440px 默认单侧栏状态画布宽度目标不少于窗口的 68%；双侧栏由用户主动固定；收起、调整尺寸和专注模式不丢失对象或草稿。

- [ ] **L02 · P1 · 重做属性面板内部布局。**
  顶部显示对象名称、预览和修改状态，随后显示地形/生态或河宽等主要字段；标记、备注和高级参数按需展开；格式刷设置只在对应工具中出现。证据：U01、U04、U07。依赖：L01、F02。验收：单格首屏可看到并操作地形与生态；选河流即看到河流属性；无需再手动配对工具栏与四个固定页签。

- [ ] **L03 · P0 · 修复窄屏遮挡并建立窄屏布局规则。**
  先修复抽屉内容区、滚动留白与固定操作栏的重叠，再提供收起、半屏和展开状态；横屏及软键盘出现时重新分配可用高度。证据：U03。依赖：无；最终布局与 L01、L02 对齐。验收：375×812、812×375 下，首尾字段及主按钮均可达且互不遮挡；操作过程中能返回地图并定位选中对象；真实手机软键盘另行实测记录。

- [ ] **L04 · P1 · 重整文档导航和保存状态。**
  地图切换、重命名、新建、导入、复制使用统一菜单及清晰分组；保存、草稿未应用、提交中、失败用不同的文字状态；窄屏仍能找到状态。证据：U02、U04、U08。依赖：L01、F02。验收：长中文名称不挤压主操作，完整名称可查看；发生失败时可直接找到重试与仍保留的草稿；菜单键盘焦点正确。

- [ ] **L05 · P1 · 提供真正的显示控制。**
  为地貌、生态、河流、标记、标签/坐标、网格建立统一可见性入口；筛选与图层可见性分开呈现，清楚显示过滤条件。证据：U05、C05。依赖：L01、F02、O01。验收：可独立检查地形和水系；临时隐藏图层不修改地图内容；编辑中和导出中使用的显示选项具有明确含义。

- [ ] **L06 · P1 · 建立可视化材料库。**
  地形和生态使用带实际渲染样本的卡片，支持搜索、分组、最近使用及当前材料预览；材料组合约束直接可见。证据：U06、C01、C03、C04。依赖：T01、T02、T04、L01。验收：从空地图可以选择材料后直接绘制；所有地形都可发现；林地改湖泊时明确展示生态的调整结果，无需先猜测清空顺序。

- [ ] **L07 · P1 · 建立全图对象查找。**
  河流列表提供全图/当前区域范围、名称搜索、分页或虚拟列表、定位和选中状态；移除界面前 200 项截断造成的不可发现对象。证据：U05、U07。依赖：L01、F03。验收：超过 200 条河流时仍能查找最后一条；视口外河流可以定位并进入编辑；查询结果不覆盖当前草稿。

- [ ] **L08 · P1 · 重做材料笔刷、取样和格式刷。**
  支持从材料库绘制、从地图取样、选择刷入字段及预览影响范围；工具提示说明当前材料、范围和操作方式。证据：U04、U06。依赖：L06、L02。验收：绘制新地形无需先创建源格；预览与最终结果一致；一次拖动形成一次撤销，取消手势不写入数据。

- [ ] **L09 · P1 · 重做多选和批量属性。**
  统一选择数量、范围、混合值和保持/设置/清除的表达；提交前突出真正会改变的字段及影响数量；全图替换保留预演。证据：U04。依赖：L02、V04。验收：用户能区分“多选中值不同”与“将清空”；切换视口不改变选区；批量操作只修改明确指定字段。

- [ ] **L10 · P2 · 整合历史、任务进度与帮助。**
  历史进入独立入口，显示动作对象及结果；导入导出任务提供稳定的进度、取消和下载入口；帮助在相关工具附近说明快捷键及手势。证据：U04、U05。依赖：L01、L04。验收：查看历史或任务不替换正在编辑的对象；失败、取消与成功有各自明确状态；新手能在界面找到工具操作说明。

## C. 字体、配色、控件与反馈（5 项）

- [ ] **V01 · P1 · 提升文字可读性。**
  主要界面正文与字段以 14px 左右为起点，减少 10—11px 关键文字；普通界面文字按至少 4.5:1 设计；地图文字根据底色选择深浅色、衬底或描边。证据：U02、C05。依赖：F02、T02。验收：所有主题中主要文本达标；深海、熔岩原等样例的标签能读清；不把字号缩小作为解决拥挤的常规办法。

- [ ] **V02 · P1 · 统一图标和控件。**
  统一 SVG 图标、线宽、按钮层级、表单尺寸和工具提示；替换顶栏含义不明确的字符图标；触摸主操作采用至少 44px 的项目目标尺寸。证据：U02、U03、U04。依赖：F02。验收：图标含义可通过文字或提示获得；鼠标、键盘、触摸都有可见反馈；危险动作与普通修改不混成一排同权重按钮。

- [ ] **V03 · P1 · 完整覆盖深浅主题和浮层。**
  菜单、对话框、选择框、任务提示和空状态使用主题变量；地图配色独立设置，并控制画布外背景与界面的亮度衔接。证据：U08。依赖：F02、O04。验收：深色状态打开导出、帮助、草稿提示和连接设置时层级一致；主题切换不会改变导出图片的地图样式。

- [ ] **V04 · P1 · 定义地图上的选择与标签层次。**
  区分悬停、键盘焦点、单选、多选、笔刷预览和未提交河流；标签按重要性避让水系和密集符号，当前对象信息始终可找。证据：U04、C05、R03。依赖：F02、O01。验收：反馈能叠加而不互相抹掉；隐藏网格后仍看得到选区；河流不盖住必须读取的活动对象信息；缩小后不出现密集文字糊团。

- [ ] **V05 · P2 · 整理文案、密度和异常状态。**
  明确“应用修改”“结束绘制”“保存文件”等动作的对象；为无地图、空地图、无结果、加载和失败设计有层级的内容；检查长名称、长备注及中文换行。证据：U01、U04、U07。依赖：L02、L04、F02。验收：每种状态都有明确的下一步；文本不溢出控件；高级参数说明按需出现，不长期挤占主要字段。

## D. 地形、生态、符号与图例（8 项）

- [ ] **T01 · P1 · 整理地形分类和概念说明。**
  重新组织地貌显示分组，说明海岸、河口、三角洲、湿地、谷地及盆地；清楚区分水域格子与河流对象；检查地形/生态组合和选择过程中的约束提示。证据：C04、U06。依赖：F01。验收：36 种地形、30 种生态都有可发现的入口与短释义；分组调整不更改旧数据键；常用地形转换不形成隐藏选项的操作死角。

- [ ] **T02 · P1 · 建立有语义的地形色板。**
  按水域、低地、山地、干旱、冰雪、火山等组织颜色和明暗，降低相邻近似地形的混淆；检查与生态纹理、河流和标签叠加后的效果。证据：C01、C05。依赖：F01、T01。验收：海陆和主要地貌家族在缩略图仍可辨；灰度及常见色觉差异模拟中有符号补充；颜色不被标注为没有数据支持的真实海拔/水深。

- [ ] **T03 · P1 · 增加地貌形状线索。**
  为山地、丘陵、高原、峡谷、沙丘、冰川等设计轻量地貌符号或线纹，处理与森林等生态叠加的避让。证据：C01。依赖：T01、T02、F02。验收：山地、平原和沙丘不需要仅靠色差识别；同一地形连续区域没有机械重复的满格大图标；符号不遮住河道及主要标签。

- [ ] **T04 · P1 · 重做生态纹理与缩放密度。**
  先区分主要生态家族，明确相近亚类在何种尺度展示额外细节；处理温带雨林与季雨林共用纹理的问题；让裸地、森林、草地和湿地有可解释的区别。证据：C02。依赖：T01、T02。验收：纹理样本和地图效果一致；裸地不会被误读为草地；林地近景可区分主要类型，远景没有点纹和波纹形成的视觉噪声。

- [ ] **T05 · P1 · 用图形表达常见标记。**
  为山峰、瀑布、洞口、绿洲、陨坑等提供统一符号；定义多标记的优先级、碰撞处理和悬停说明；英文缩写保留在参考信息中。证据：C03。依赖：F02、T03、V04。验收：常用标记可通过图例迅速理解；多个标记同格不会互相覆盖；所有原有标记数据仍可查看和编辑。

- [ ] **T06 · P1 · 建立可交互且可导出的图例。**
  画布提供简明图例，材料库提供完整图例；支持查看本图使用的类型、解释组合样式并临时高亮对应对象。图例样本由实际渲染配置生成。证据：C03、U05。依赖：T02、T03、T04、T05、O01。验收：新增或调整样式后各处图例同步；图例高亮不修改地图；地图读者能在一个入口解释地形、生态、标记及河流宽度的视觉含义。

- [ ] **T07 · P1 · 处理连续区域和水陆边界。**
  从现有格子生成连续水面及岸线，定义海岸、沙滩、湿地过渡和内部网格的显示强度；保持编辑格子的定位与命中清楚。证据：C01、C05、R04。依赖：T02、O01。验收：相邻水域没有不必要的内部岸线；海岸线可与河口连续连接；关闭网格后水陆边界仍准确，区域轮廓与原格子语义相符。

- [ ] **T08 · P1 · 定义远、中、近景信息层次。**
  分级调整网格、地貌符号、生态纹理、标记和坐标密度；远景单独保留河网线索，替代“含河流就把整块染蓝”的表达。证据：C02、C05。依赖：T03、T04、V04、R02、O05 的性能基线与预算。验收：缩放时信息渐进出现，阈值附近不反复闪变；远景可辨地貌和主要水系，放大后位置与形状一致；不误增湖泊或水域面积。

## E. 河流几何、水系连接与直接编辑（11 项）

- [x] **R01 · P0 · 修复河宽插值。**
  用沿路径累计距离计算宽度锚点之间的变化，明确宽度是地图单位；把“无宽度控制点”与“显式宽度锚点”区分开。证据：报告 R01。依赖：无；发布前完成 F04。验收：R0C0 宽 2 到 R0C10 宽 22，在 R0C1 插入无宽度控制点后，该位置仍为 4；不改变几何的节点细分不会改变沿线宽度。

- [ ] **R02 · P0 · 修复范围裁切和边界连续性。**
  保留河道样本的连续段，处理范围边界交点和足够的曲线邻域；禁止把过滤后的不连续片段直接相连。证据：报告 R02。依赖：无。验收：离开再进入、多次进出、贴边及极宽河道都无假连线；区域输出与全图同位置裁切一致；平移视口不生成新端帽或异常增宽。

- [ ] **R03 · P1 · 改善弯曲和河带几何。**
  限制曲线过冲，处理宽河急弯、内岸退化、重复点、短段和折返；选择稳定的转角、端帽及重叠合成规则。证据：报告 R05。依赖：R01、R02、F03。验收：固定压力样例无尖刺、破洞或意外翻折；不自交中心线的合理宽度样例不会凭空出现环；退化输入有确定行为，不能产生非法坐标。

- [ ] **R04 · P1 · 实现可编辑的流向和连接关系。**
  提供端点吸附、连接提示、建立/解除连接和流向反转；交叉与连接使用不同状态，连接编辑作为完整命令提交。证据：报告 R03、R06。依赖：F03、F04、R09。验收：移动汇流节点不会留下断缝；解除连接不会意外移动其他河道；反转流向保留原位置的宽度；旧图未指定的关系不被擅自补全。

- [ ] **R05 · P1 · 重做支流交汇。**

### 第一阶段的具体顺序

1. 保留当前裁切、河宽和窄屏样例，以及用于兼容检查的旧地图副本。
2. 修复裁切产生的错误连线，检查离开后重入、多次进出、贴边和区域导出。
3. 明确旧宽度的保留与恢复方式，将河宽插值修复和宽度兼容作为同一交付批次；核对节点细分、旧图读写及历史恢复。
4. 修复窄屏抽屉的内容高度、滚动留白和固定操作栏，验证竖屏及横屏。
5. 为上述真实缺陷补齐行为回归并提交阶段结果。新的抽屉交互和真实软键盘验收分别在阶段 3、8 收尾。

### 必须遵守的前置关系

- O01 共享绘图规则先于地形符号、图例和导出界面，避免画布和输出分别实现一遍。
- F04 的宽度兼容与 R01 同批交付；其余新水系字段的读写、历史及恢复先于 R04 连接编辑。
- T01 分类与 T02 色板先于材料库和图例；材料库 L06 先于新的材料笔刷 L08。
- 工作区布局 L01 和属性 L02 先于河流直接编辑 R09；节点编辑稳定后再加入宽度手柄和连接操作。
- R03 河带几何、T07 水面边界与 R04 连接关系先于汇流、入海和湖泊合成；分汊在这些基础上完成。
- O04 样式版本先于 V03 的完整主题验收；地图主题与工作区主题的对应规则在地形阶段完成。
- O05 从阶段 2 开始记录基线，地形纹理、河流合成等新增成本出现时即复测，在阶段 7 收尾。

### 过程验证和提交安排

- 按可独立验收的改动提交推送：首批可分为裁切修复、河宽及兼容、窄屏修复；大型阶段按共用规则、界面流程和地图表现拆分。
- 每个界面阶段都检查桌面、窄屏、焦点和草稿保留，每个地图阶段都比较画布与导出。阶段 8 负责全流程验收和前面无法覆盖的真实设备/使用者验证。
- 迁移、命令、几何等行为变更执行相关回归；共享契约变更完成完整检查；纯视觉细节以固定样例与实际操作核对。
- 阶段退出条件不满足时先处理该阶段遗留；只推进不依赖它的工作。实施中调整顺序时同步记录原因和影响。

1. 用户能够看出当前工具、选中对象、修改内容与提交状态；常用操作在当前上下文可达。
