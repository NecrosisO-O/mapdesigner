# 重构后的固定样本测量

环境：Node v24.16.0，macOS arm64。本次测量日期：2026-10-03。
每个探针创建独立临时 SQLite 数据库；一格修改先预热，再取五次中位数。
对比值来自 2026-10-02 同机审查记录。数值是本机样本，不是所有部署环境的性能承诺。

| 已设计格数 | 原一格修改中位数 | 本次一格修改中位数 |
| --- | --- | --- |
| 10,000 | 0.60 ms | 0.307 ms |
| 100,000 | 4.01 ms | 0.270 ms |
| 500,000 | 22.17 ms | 0.240 ms |

统计更新只处理发生变化的格子；新增/删除时利用有序索引查找边界，普通属性修改不再扫描整图。
16,000 格河流直线路径生成中位数由约 184 ms 降至 0.870 ms，去重使用集合，控制点宽度采用两次遍历。
150,000 格、10.86 MB JSON 导入成功，本机约 494 ms。原探针曾在边界计算中发生参数数量导致的栈溢出。

远景接口对整个请求范围生成最多 64 × 64 个聚合块，包含边缘格子和河流覆盖；放大后切换到精确单元格。
前端范围缓存最多八项、加权 60,000 格/河流控制点/概览块。超预算的单次响应不进入缓存。
河流样本缓存最多 128 项和 100,000 个路径样本，缩放仅跨细节阈值时重建场景。

原始输出见 edit-performance.json、river-performance.json、import-performance.json。
复现命令：构建后运行上一目录的 probe-backend.mjs，参数分别是 single_cell_edit_scaling、river_line_scaling、import_150000_cells。
