# 验收记录

这里保留支撑当前功能的验收结论和必要数据。版本变化见 [CHANGELOG](../../CHANGELOG.md)，执行方法见[开发指南](../development.md)。

## 视觉与交互

2026-10-03 的 RC1 验收覆盖材料搜索、取样与笔刷、单格和批量草稿、对象定位、河流节点/宽度/连接、导出预览、主题和键盘焦点。维护者已完成实际使用验收。

14 组[固定场景](../design/fixtures/cartography-gallery.json)及 [PNG 对照](../design/gallery/)覆盖森林山地、荒漠冰雪、密集标记、急弯、交汇、入海、穿湖和三角洲。宽度、裁切、连接、湖面与导出一致性另有行为或像素回归。相近生态仍需近景和图例识别；灰度及色觉模拟用于辅助设计检查。

四种 CSS 视口（375×812、812×375、1024×768、1440×900）的导出字段与操作区可达且没有水平溢出，见[布局数据](./visual/layout-final.json)。14 组文字对比度均至少 4.5:1，浅色最小 5.10、深色最小 5.07，见[对比度数据](./visual/contrast.json)。

同机浏览器测量使用 Apple M5、Node 24.16；正式画布实际加载 1200 格及长河，预热 10 次、采样 40 次。帧耗时为 rAF 间隔，交互时间近似为事件至两次 rAF，排除网络读取。原始数据见[浏览器性能](./visual/browser-performance.json)。

| 地图摘要总格数 | 帧 P95 | 交互 P95 |
| ---: | ---: | ---: |
| 10,000 | 18.6 ms | 41.6 ms |
| 100,000 | 16.7 ms | 42.3 ms |
| 500,000 | 16.8 ms | 39.3 ms |

摘要总数不表示浏览器同时渲染全部格子。CSS 视口、浏览器页面缩放和真实触控是不同验证条件。RC1 对应提交 `db5c906` 通过构建、类型检查、214 项测试及生产容器验证。

## 大地图与 RC2

2026-10-04 完成 11 万至 2300 万格合成样本容量测量，以及百万格合并、持久撤销/重做、JSON 往返和区域分块输出。桌面与窄屏验证包含深色导出、合并、百万格文件导入及局部编辑。数据、截图和测量边界见[容量与流程记录](./large-map-capacity/README.md)。

RC2 的构建、类型、235 项测试、格式和生产容器验证通过。配置上限及升级步骤统一维护在[部署说明](../deployment.md)，具体提交状态以对应 CI 为准。
