## 新增记录

记录日期、提交、工具链、机器、样本来源、执行命令、统计方法与结论。区分数据库耗时、Node 绘图耗时和浏览器帧耗时；CSS 视口检查、浏览器页面缩放、真实设备输入各自登记。

维护脚本先把报告输出到系统临时目录或显式指定的位置；选取需要长期保留的报告及截图，复制到新的日期或阶段目录后补充说明。固定数据、原始报告和结论应能互相对应。脚本参数与副作用见[维护脚本说明](../../scripts/README.md)。
